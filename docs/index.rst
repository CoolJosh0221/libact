libact: Pool-based Active Learning in Python
============================================

`libact` is a Python package designed to make active learning easier for
real-world users. The package implements several active-learning strategies,
including the `active learning by learning
<https://www.csie.ntu.edu.tw/~htlin/paper/doc/aaai15albl.pdf>`_ meta-strategy,
and provides interfaces for extending strategies, models, and labelers.
